# volley-bot

Телеграм-бот для закрытой группы волейболистов: каждый день сам ставит опрос на игру,
следит за плюсами и закрывает опрос, когда состав набран.

Требования и ограничения Telegram API — в [REQUIREMENTS.md](REQUIREMENTS.md).

## Что делает

| Когда | Что |
|---|---|
| 09:00 (Europe/Sofia) | постит неанонимный опрос «‹дата› Игра 18-00»: `Плюс` / `Минус` / `Ответ до 16-00` и закрепляет его |
| 15:45 | тегает тех, кто выбрал «Ответ до 16-00», и просит определиться |
| 8-й плюс | один раз пишет «Кворум есть — игра состоится» и перечисляет плюсанувших без тегов |
| 12-й плюс | сразу закрывает опрос и постит состав с тегами |
| 17:00 | закрывает опрос, если ещё открыт: при 8+ «Играем, N человек», иначе «игры сегодня нет» |

Команды для админов группы: `/poll` — опрос вне расписания, `/close` — закрыть досрочно,
`/status` — сколько плюсов сейчас.

## Почему опрос неанонимный

Telegram отдаёт боту голоса (`poll_answer`) только для неанонимных опросов и только для тех,
что бот отправил сам. С анонимным опросом ни автозакрытия по 12 плюсам, ни тегов не бывает —
вообще. Побочный эффект: в группе видно, кто как проголосовал.

## Первый запуск

1. Создать бота у @BotFather, забрать токен.
2. Добавить бота в группу и **дать права администратора**: отправка сообщений (опросы) и
   закрепление. Без админки участникам группы опросы запрещены, и бот не сможет постить.
3. Токен — в `.env` (см. `.env.example`). Первый чат, куда бота добавили, запоминается
   автоматически; посторонний чат привязку уже не перетянет.
4. Если бота добавили днём и опрос нужен сегодня же — админу дать `/poll`: расписание
   само сработает только в 09:00 следующего дня.

Старт процесса занимает ~12 секунд: столько импортируется aiogram (pydantic строит
~700 моделей). Это не зависание — `systemctl status` в это время уже показывает `active`,
а `Run polling for bot @…` появляется в журнале после.

## Приёмка после добавления в группу

1. Бот пишет приветствие сразу при добавлении. Молчит → нет права писать в группу.
2. Админ даёт `/poll` → появляется закреплённый неанонимный опрос. Не появился → смотреть
   `journalctl -u volley -n 30`: обычно не хватает прав администратора на опросы или пин.
3. Проголосовать «Плюс», потом снять голос → `/status` показывает счёт по своим данным и
   должен меняться. Не меняется → бот не получает `poll_answer`: опрос анонимный или
   отправлен не ботом.
4. `/close` → опрос закрывается, в чат уходит итог.

## Локально

```bash
uv venv .venv --python 3.12
uv pip install --python .venv/bin/python -r requirements-dev.txt

.venv/bin/python -m pytest -q            # тесты
.venv/bin/python scripts/smoke_updates.py # контракт с aiogram: подписка на poll_answer
bash scripts/mutations.sh                # испытание тестов мутациями

set -a && . ./.env && set +a && .venv/bin/python -m volley
```

## Деплой

Адрес сервера в репозиторий не попадает: скопируй `deploy/target.env.example` в
`deploy/target.env` и впиши свой хост.

```bash
bash deploy/deploy.sh
```

Скрипт идемпотентный: разворачивает при первом прогоне, обновляет при следующих.
Код — `/opt/volley`, база — `/var/volley/state.db`, юнит — `volley.service`.
Токен в `/opt/volley/.env` деплой не перезаписывает.

```bash
. deploy/target.env
ssh "$VOLLEY_SSH_HOST" "systemctl status volley"
ssh "$VOLLEY_SSH_HOST" "journalctl -u volley -n 50 -f"
```

## Устройство

| Файл | Ответственность |
|---|---|
| `volley/domain.py` | подсчёт голосов и решения — без Telegram и без БД |
| `volley/store.py` | состояние в SQLite: опросы, голоса, `chat_id` |
| `volley/texts.py` | тексты для группы; теги только там, где пинг уместен |
| `volley/schedule.py` | когда создавать и когда закрывать, включая catch-up после простоя |
| `volley/service.py` | действия в Telegram и обработка сбоев API |
| `volley/handlers.py` | апдейты: привязка к группе, миграция chat_id, голоса, команды |
| `volley/__main__.py` | сборка: long polling + три будильника расписания |
